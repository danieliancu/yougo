Remove automatic booking status change from WhatsApp booking change requests.

Current issue:
ConversationService::recordPendingBookingChangeRequest() changes the linked booking status to pending when a change request is recorded.

This is risky because a WhatsApp customer asking to change/reschedule/cancel should not automatically alter the operational booking status.

Goal:
- Keep recording booking_change_requests in conversation metadata.
- Keep email notification behavior.
- Keep notified_at behavior.
- Keep dashboard indicator.
- Do NOT automatically change booking.status.
- The booking status should remain unchanged until the business explicitly updates it.

Update tests:
- when a change request is recorded for an approved/confirmed/completed booking, booking.status remains unchanged.
- metadata booking_change_requests is still created.
- notification still sends if enabled.

Run php artisan test and npm run build.

Commit:
git commit -m "Keep booking status unchanged for change requests"
